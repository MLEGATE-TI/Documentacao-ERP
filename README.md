# Documentação do ERP Mlegate

Documentos de desenho do ERP (dicionário de dados por fase, detalhamentos, consolidações e pendências), em Markdown na pasta `documentos/`.

Origem: cópia dos 77 documentos do projeto ERP no claude.ai, tirada em 2026-11-11 (dicionário da Fase 0 na revisão 79). A partir daqui, esta é a fonte da documentação: alterações entram por commit neste repositório.

Os documentos antigos que já tinham saído do projeto (15 a 28, 30, 45, 47, 52, 58, 84 a 88, 92 e 97) ficam só como histórico no repositório do ERP, em `docs-alberto/`.
